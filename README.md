# 吉安水务 - Home Assistant 自定义集成

Home Assistant custom integration for 吉安水务 (Ji'an Water Service)。

## 功能特性

- **多户号支持**：支持同时监控多个水费户号
- **实时数据**：当月水费、用水量、余额、缴费状态等实时数据
- **历史记录**：自动保存历史月份的用水量和费用记录
- **欠费提醒**：通过二值传感器监控欠费状态
- **自动续命**：15 分钟轮询保持 JSESSIONID 有效，无需频繁手动更新

## 安装方法

### 方法一：通过 HACS 安装（推荐）

1. 在 Home Assistant 中安装 [HACS](https://hacs.xyz/)
2. 打开 HACS → 集成 → 浏览 → 右上角菜单 → 自定义仓库
3. 添加本仓库 URL：`https://github.com/ytcquqyl/jaswjt-ha`
4. 在 HACS 中搜索"吉安水务"并安装
5. 重启 Home Assistant

### 方法二：手动安装

1. 下载或克隆本仓库
2. 将 `custom_components/jaswjt/` 文件夹复制到 Home Assistant 的 `/config/custom_components/` 目录下
3. 重启 Home Assistant

### 验证安装

重启后，进入 **设置 → 设备与服务 → 添加集成**，搜索"吉安水务"，如果能找到则安装成功。

## 配置步骤

### 1. 获取 JSESSIONID

JSESSIONID 是吉安水务小程序的登录凭证，需要通过抓包获取：

1. **手机准备**：在手机上安装 Charles 或 Fiddler 抓包工具（需越狱或电脑端代理）
2. **设置代理**：在手机上设置 HTTP 代理，指向电脑 IP 和抓包工具端口（如 `192.168.1.100:8888`）
3. **信任证书**：在手机上安装并信任抓包工具的 SSL 证书
4. **打开小程序**：微信中打开"吉安水务"小程序
5. **抓包**：在 Charles 中找到 `www.jaswjt.com` 的请求，找到 `method=userinfo` 的请求
6. **提取 JSESSIONID**：查看该请求的响应头，找到 `Set-Cookie` 字段中的 `JSESSIONID=xxxxxxxxxxxx` 值

**提示**：如果找不到 `method=userinfo` 请求，可以尝试打开小程序的"我的"或"查询"页面，触发数据请求后再查看。

### 2. 配置集成

1. 进入 **设置 → 设备与服务 → 添加集成**
2. 搜索"吉安水务"并点击
3. 填写 JSESSIONID（从上面步骤获取的值）
4. 填写户号（多个户号用逗号分隔，如 `12345678, 87654321`）
5. 点击"提交"

### 3. 查看数据

配置完成后，可以在 Home Assistant 的仪表盘中创建卡片显示水费数据。

## 实体说明

### 传感器（sensor）

每个户号会创建以下传感器：

| 实体 | 说明 |
|------|------|
| 月份 | 当前账单月份（如 `2026年08月`） |
| 户号 | 水费户号 |
| 户名 | 户主姓名 |
| 地址 | 用水地址 |
| 用水量 | 当月用水量（吨） |
| 本期抄见 | 本期水表读数 |
| 上期抄见 | 上期水表读数 |
| 基本水费 | 基本水费（元） |
| 污水处理费 | 污水处理费（元） |
| 其他费用 | 其他费用（元） |
| 垃圾费 | 垃圾处理费（元） |
| 水费 | 水费（元） |
| 滞纳金 | 滞纳金（元） |
| 费用合计 | 总费用（元） |
| 费用状态 | 缴费状态（已缴/未缴） |
| 余额 | 账户余额（元） |

**历史数据传感器**：

对于核心指标（用水量、费用合计），系统会为每个历史月份创建独立传感器：
- `用水量 2026年07月`
- `费用合计 2026年07月`
- `用水量 2026年06月`
- `费用合计 2026年06月`
- ...

### 二值传感器（binary_sensor）

每个户号会创建一个：

| 实体 | 说明 |
|------|------|
| 是否欠费 | 当费用状态为"未缴"时为 on，否则为 off |

## JSESSIONID 有效期

- 默认有效期：约 1 小时
- 自动续命：集成每 15 分钟轮询一次 API，会刷新 JSESSIONID 的滑动窗口
- **只要 Home Assistant 正常运行，JSESSIONID 会一直保持有效**
- 如果 HA 停止运行超过 1 小时，JSESSIONID 可能过期，需要重新获取

## 常见问题

### Q: 配置时提示"会话无效或已过期"怎么办？

A: JSESSIONID 可能已过期，请重新抓包获取新的 JSESSIONID。

### Q: 实体显示"unknown"怎么办？

A: 
- 确认 JSESSIONID 有效
- 检查户号是否正确
- 重启 Home Assistant

### Q: 如何添加更多户号？

A: 编辑集成配置，在户号字段中添加更多户号，用逗号分隔。

### Q: JSESSIONID 过期后如何更新？

A: 
1. 重新抓包获取新的 JSESSIONID
2. 在集成设置中更新 JSESSIONID
3. 或者删除并重新添加集成

### Q: 为什么没有历史数据？

A: API 只返回最近 5 个月的数据。首次配置后，系统会自动保存历史数据，之后即使 API 不再返回旧月份，数据也会保留。

## 技术细节

- **数据来源**：吉安水务微信小程序 API (`www.jaswjt.com/WeChatNewsJAS`)
- **轮询间隔**：15 分钟
- **IoT 类型**：Cloud Polling
- **依赖**：无（无需额外安装 Python 包）
